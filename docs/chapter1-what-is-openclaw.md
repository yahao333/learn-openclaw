# 什么是 OpenClaw？

🤔 你可能听说过 ChatGPT，但 OpenClaw 比它更强大！

## 一句话解释

**OpenClaw = 你的私人 AI 助手**，它可以 24 小时帮你干活，而且数据都存在你自己电脑上，隐私安全。

## 🆚 OpenClaw vs 普通 AI

| | 普通 AI（ChatGPT） | OpenClaw |
|---|---|---|
| 响应方式 | 你问一句，它答一句 | 你告诉它要做什么，它帮你完成 |
| 运行时间 | 每次都要手动打开 | 24 小时待命，自动执行 |
| 接入方式 | 只能网页聊天 | 微信、飞书、钉钉都能控制 |
| 数据存储 | 云端（隐私担忧） | 本地（自己电脑） |

## 🎯 OpenClaw 能做什么？

### 场景 1：早上自动推送

你还在睡觉时，OpenClaw 已经帮你：
- 📅 查好今天的日程
- 🌤️ 查看明天天气
- 📰 整理好新闻摘要

早上醒来打开手机，AI 已经把所有信息整理好发给你了！

### 场景 2：文件整理

你只需要说：
> "帮我把下载文件夹里的文件按类型整理"

OpenClaw 就会自动：
- 把图片移到「图片」文件夹
- 把文档移到「文档」文件夹
- 删除超过 30 天的垃圾文件

### 场景 3：智能客服

接入微信/飞书后：
- 自动回复客户问题
- 24 小时在线
- 不用休息

## 🏗️ 技术架构

OpenClaw 由两部分组成：

### 1. Gateway（网关）
> 像是公司的前台，负责接待来访者

- 接收来自微信、飞书、钉钉的消息
- 把消息转发给 AI 处理

### 2. Agent（执行者）
> 像是公司的员工，负责实际工作

- 理解你要做什么
- 调用各种工具完成任务

### 4. 💰 免费开源
