# 什么是 OpenClaw？

## OpenClaw 简介

OpenClaw 是一款开源的自托管 AI Agent（智能体）框架，前身是 Clawdbot/Moltbot。它被誉为"开源版 JARVIS"或"数字打工人"，能够帮助你自动化处理各种日常工作。

## OpenClaw vs 传统 AI 聊天机器人

| 特性 | 传统 AI（如 ChatGPT） | OpenClaw |
|------|----------------------|----------|
| 交互方式 | 被动对话 | 主动执行 |
| 工作模式 | 问一句答一句 | 24 小时待命，自动执行 |
| 数据存储 | 云端 | 本地自托管 |
| 平台接入 | 仅网页 | 多平台（Telegram、飞书等） |

## OpenClaw 的核心架构

OpenClaw 主要由两部分组成：

### 1. Gateway（网关）
网关是 OpenClaw 的入口，负责：
- 接收来自各个平台的消息
- 管理用户会话
- 协调 Agent 的工作

### 2. Agent（执行引擎）
执行引擎是 OpenClaw 的核心，负责：
- 理解用户意图
- 规划和执行任务
- 与外部工具交互

## OpenClaw 的特点

### 1. 真正的 AI Agent
OpenClaw 不是简单的聊天机器人，它能够根据你的指令主动去完成任务。

**举例**：
- 你说"明天早上 7 点叫我起床"，OpenClaw 会设置定时任务，明天准时推送叫醒信息
- 你说"帮我整理一下上周的邮件"，OpenClaw 会自动分析邮件并生成摘要

### 2. 自托管 & 高隐私
- 数据存储在本地，安全性高
- 不依赖第三方云服务
- 完全可控

### 3. 多模型支持
支持接入多种 AI 大模型：
- 千问（Qwen）
- GPT-4
- Claude
- 等等

### 4. 多平台接入
可以通过多种通讯平台控制：
- Telegram
- 飞书
- WhatsApp
- Discord
- Slack

### 5. 丰富的工具生态
OpenClaw 可以操作：
- 文件系统
- 执行脚本
- 收发邮件
- 浏览器自动化
- 数据库操作

## OpenClaw 生态

OpenClaw 发展出了多个衍生版本：

| 版本 | 特点 |
|------|------|
| NanoClaw | 轻量化版本，适合资源有限的设备 |
| IronClaw | Rust 性能版，执行效率更高 |
| OpenClaw Web | Web 管理界面版本 |

## 为什么要学习 OpenClaw？

1. **拥有私人 AI 助手**：打造属于你自己的 JARVIS
2. **自动化工作**：让 AI 帮你处理重复性任务
3. **保护隐私**：数据本地存储，安全可控
4. **开源免费**：完全免费，可以自定义修改
