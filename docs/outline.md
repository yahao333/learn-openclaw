## 🚀 学习路线推荐

### 零基础小白路线
```
1. 阅读"什么是 OpenClaw" → 了解概念
   ↓
2. 按照"安装教程"操作 → 安装软件
   ↓
3. 跳过配置，直接运行 → 先跑起来
   ↓
4. 选一个"实战项目" → 动手实践
```

### 进阶玩家路线
```
1. 安装 OpenClaw
   ↓
2. 接入千问/文心 AI → 体验 AI 对话
   ↓
3. 接入飞书/微信 → 用通讯软件控制
   ↓
4. 定制自己的 AI 助手
```
