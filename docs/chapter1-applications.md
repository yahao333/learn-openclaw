# OpenClaw 能做什么？

🎉 看完这一章，你就知道 OpenClaw 有多强大了！

## 🎯 实际应用场景

### 1. 📅 日程管理小助手

**场景**：每天早上自动推送今日日程

**你能这样指挥它**：
> "明天下午 3 点提醒我开会"
> "每天早上 8 点叫我起床"
> "下周一的会议提前 15 分钟提醒"

**OpenClaw 帮你**：
- ⏰ 定时提醒
- 📱 微信/飞书推送
- ✅ 完成确认

## 🎮 进阶玩法

### 自动化工作流

```
触发条件 → 执行动作 → 通知结果
   ↓          ↓           ↓
  定时      查天气      推送到微信
```

### 定时任务

```yaml
scheduled_tasks:
  - name: "早上推送"
    time: "7:00"
    action: "推送天气+日程"

  - name: "下班检查"
    time: "18:00"
    action: "检查未处理邮件"
```
