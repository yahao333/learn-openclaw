## 什么是 OpenCLAW？

OpenCLAW 是一个开源的编程语言和开发框架，是对经典 CLAW 语言的现代化重新实现。简单易学，功能强大，非常适合编程新手入门。

## 特性

- **简单易学**：语法简洁，入门门槛低
- **功能强大**：支持 Web 开发、自动化脚本、数据处理
- **中文教程**：全简体中文内容，面向零基础小白
- **实战项目**：包含计算器、待办事项等完整项目

## 快速开始

### 安装 OpenCLAW

```bash
# macOS
brew install openclaw

# Linux
sudo apt-get install openclaw

# 验证安装
claw --version
```

### 运行第一个程序

```claw
print("Hello World!")
```
